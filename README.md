# ケアスイート for Claude

介護施設の現場業務を、AI（Claude）でサポートする無料ツールキットです。
インストール不要・登録不要で、ブラウザだけで動作します。

## 使い方

`index.html` をブラウザで開くと、ツール一覧（LP）が表示されます。
GitHub Pages 等で公開すれば、そのまま現場で利用できます。

## 収録ツール（全12種）

### 記録・モニタリング
| ツール | 内容 |
|---|---|
| 介護記録 作成支援 (`tools/care-record.html`) | メモから記録文（SOAP/経過記録等）を整える |
| 水分摂取 記録・管理 (`tools/hydration.html`) | 水分量を記録し目標達成度を自動集計 |
| バイタル記録 (`tools/vitals.html`) | 体温・血圧等を記録し基準値外を自動ハイライト |
| 食事摂取量 記録 (`tools/meal.html`) | 主食・副食を割合で記録し低栄養リスクを検知 |

### 業務・運営
| ツール | 内容 |
|---|---|
| シフト作成ツール (`tools/shift.html`) | 職員・希望休・配置ルールから公平なシフト案を生成 |
| 加算区分 判定ツール (`tools/kasan.html`) | 体制チェックで検討対象の加算を一覧化 |
| 申し送り 作成支援 (`tools/handover.html`) | 利用者別メモから漏れのない申し送り文を整形 |
| ケアプラン 文案作成 (`tools/care-plan.html`) | アセスメントから計画書の文案（下書き）を作成 |

### 安全・ケアの質
| ツール | 内容 |
|---|---|
| 服薬管理 (`tools/medication.html`) | 服薬スケジュール登録と時間帯別チェックリスト |
| ヒヤリハット報告 (`tools/incident.html`) | 5W1Hから要因分析・再発防止策つき報告書を作成 |
| 転倒リスク評価 (`tools/fall-risk.html`) | チェック項目でリスクをスコア化し対策を提示 |
| レクリエーション企画 (`tools/recreation.html`) | 条件に合うレク案を進行台本つきで提案 |

## 仕組み

- 入力フォームの内容は、必要なものは **ブラウザ内（localStorage）にのみ保存** され、外部送信しません。
- 各ツールは「Claude用プロンプト生成」ボタンで指示文を作成します。コピーして [Claude](https://claude.ai/) に貼り付けるだけで、文章生成や助言が得られます。

## 注意事項

- 本ツールは業務支援用のプロトタイプです。
- 加算の算定要件・医療判断・ケアプランの最終決定などは、**必ず最新の公的情報および専門職の確認** を行ってください。
- 利用者名は記号・イニシャルに置き換えるなど、施設の個人情報ルールに従ってご利用ください。
